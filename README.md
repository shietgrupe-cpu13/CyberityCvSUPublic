# Cyberity

**Cybersecurity Awareness and E-Learning Android Application**

Cyberity is a Cavite State University capstone project designed to help students improve cybersecurity awareness through interactive lessons, quizzes, and practical simulations.

## Features

- Six learning units covering cybersecurity fundamentals, account security, phishing and social engineering, malware, network security, and incident response
- Interactive learning activities, quizzes, and simulations
- Learning progress tracking, experience points, hints, hearts, and daily streaks
- Student leaderboards and PDF completion certificates

## Technology

Developed for Android using Kotlin, Jetpack Compose, Firebase Authentication, and Cloud Firestore.
